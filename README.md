# 🚀 Поймай астероид

Небольшая браузерная аркада на чистом HTML5 Canvas: управляй космическим кораблём и лови падающие астероиды, пока не закончится время или жизни.

## Игровая механика

- Корабль двигается по горизонтали внизу игрового поля.
- Сверху вниз падают астероиды со случайных позиций.
- Пойманный астероид (столкновение с кораблём) — **+1 очко** и вспышка с частицами.
- Пропущенный астероид (долетел до низа поля) — **−1 жизнь**.
- В начале игры у игрока **3 жизни**.
- Игра длится **60 секунд** или заканчивается раньше, если жизни закончились.
- Со временем астероиды падают быстрее и появляются чаще.
- После окончания показывается итоговый счёт, причина окончания игры и лучший результат (сохраняется в `localStorage` браузера).

## Управление

- **← / →** или **A / D** — движение корабля.
- **Space** или кнопка «Старт» — начать игру.
- На мобильных устройствах — экранные кнопки ◀ / ▶.

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка, без внешних UI-фреймворков)
- JavaScript (ES6+), без сторонних библиотек
- Canvas API для отрисовки игрового поля, фона со звёздами, корабля, астероидов и частиц
- `localStorage` для хранения лучшего результата

Никаких сторонних игровых ассетов, API-ключей, авторизации или базы данных не используется — всё, включая графику, рисуется программно на `<canvas>`.

## Локальный запуск

Игра состоит из статических файлов и не требует сборки. Проще всего открыть `index.html` через любой локальный веб-сервер (открытие файла напрямую двойным кликом тоже работает в большинстве браузеров).

Вариант с Python:

```bash
python -m http.server 8000
```

Затем открыть в браузере `http://localhost:8000`.

Или просто открыть `index.html` двойным кликом в проводнике.
